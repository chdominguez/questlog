Study exactly what you need. Upload a PDF, your notes, a link to the docs or a GitHub repo, and Questie builds a course from that material: theory cards, challenges and katas based on your sources. It costs 150 credits.

## Build it

1. Press **Build** in the top bar and open the **Files** tab.
2. Press **Add files**, or drop files on the box. Uploads start at once, with a progress bar per file.
3. Optional: paste a link in **URL or repo**.
4. Pick a **Level**: **Beginner**, **Intermediate** or **Advanced**.
5. Press **Build course · 150**, then confirm **Spend 150 credits?** with **Build**.

You need at least one file or one URL.

## What you can add

| Source | Accepted |
|---|---|
| Files | PDF, Markdown and plain text |
| Number of files | Up to 10 per course |
| PDF size | Up to 20 MB each |
| Markdown or text size | Up to 500 KB each |
| URL or repo | A web page, or a public GitHub repo (Questie reads its README and the files it links) |

Your notes work best as Markdown files. See [Notes](/learn/notes/).

## Watch it being built

| Step | What happens |
|---|---|
| Reading files | Questie reads your files and links |
| Outline | The levels are planned from your material |
| Writing levels | Levels are written, with a counter |
| Checking | The course is validated against the schema and fixed when needed |
| Saving | The course is saved to your account |

You can leave while it runs; a card on **Courses** takes you back. You run one build at a time. When it is done, **Course ready** shows the levels, challenges and katas, and **Start** opens the map.

## Private by default

A course built from your own material starts private. Only you see it until you share it. See [Share and publish](/ai/publish/).

## If a build fails

If a file can't be read or a link can't be fetched, the build stops and your 150 credits come back automatically (**150 credits refunded**). Press **Edit** to change the sources, or **Try again**.
