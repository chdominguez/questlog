# Android

Generated by `npx cap add android`; web assets come from `npm run cap:sync`.

Needs JDK 21 and the Android SDK (`sdkmanager`). CI builds `assembleDebug` in `.github/workflows/mobile.yml`.

```sh
npm run cap:sync
cd android && ./gradlew assembleDebug
```

Before a release:

- `android/app/google-services.json` from the Firebase project (gitignored). Without it FCM push is off.
- OAuth Android client for `app.questie` with the debug and Play signing SHA-1; build with `VITE_GOOGLE_WEB_CLIENT_ID` set.
- `VITE_REVENUECAT_ANDROID_KEY` set at build time.
- Replace `PLAY_APP_SIGNING_SHA256` in `public/.well-known/assetlinks.json` with the Play app signing SHA-256.
- Release: `ANDROID_KEYSTORE`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`, then `./gradlew bundleRelease`.
- Icons and splash: `npx @capacitor/assets generate --assetPath resources --android --ios` (the plain `cap:assets` script also rewrites the PWA icons).
