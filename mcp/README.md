# Questie MCP server

A local stdio MCP server that lets Claude list, read, validate and save courses, upload course media, and read your notes from the app. Run it by hand with `npm run mcp`.

Tools, resources, environment and setup for Claude Code and Claude Desktop: [questie.app/authoring/mcp](https://questie.app/authoring/mcp/).

`QUESTLOG_HEADERS` (extra headers as JSON, for old login-proxy installs) is still read for one release.
