# iOS

Generated by `npx cap add ios --packagemanager SPM`; web assets come from `npm run cap:sync`. `cap sync ios` runs on Linux; building, signing and running need macOS with Xcode.

```sh
npm run cap:ios   # sync, then open in Xcode
```

Before a release (macOS):

- `ios/App/App/GoogleService-Info.plist` from the Firebase project (gitignored), and the APNs auth key uploaded to Firebase.
- Signing team in Xcode; capabilities match `App/App.entitlements` (Push Notifications, Sign in with Apple, Associated Domains) plus In-App Purchase. Set `aps-environment` to `production` for App Store builds.
- Google sign-in: add the reversed iOS client id as a URL scheme in `Info.plist` (`CFBundleURLTypes`); build with `VITE_GOOGLE_IOS_CLIENT_ID` and `VITE_GOOGLE_WEB_CLIENT_ID`.
- `VITE_REVENUECAT_IOS_KEY` set at build time.
- Replace `TEAMID` in `public/.well-known/apple-app-site-association` with the Apple team id.
